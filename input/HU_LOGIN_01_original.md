# HU: Inicio de sesion

**Como** usuario del sistema,
**quiero** iniciar sesion con mi usuario y contraseña,
**para** acceder a mi cuenta.

## Reglas de negocio

- El sistema valida usuario y contraseña y permite el acceso si son correctos.
- Si los datos son incorrectos, el sistema muestra un mensaje de error.
- Despues de iniciar sesion correctamente, se muestra una pagina de bienvenida con opcion de cerrar sesion.

## Criterios de aceptacion

- Login exitoso con credenciales validas.
- Login fallido con credenciales invalidas.
